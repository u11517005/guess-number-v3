# 猜數字遊戲版本三（雲端存檔）

## 這個版本完成什麼
- 輸入識別碼連線，不是 Google 帳號登入。
- 每局答案固定，四位數字不重複，允許開頭為 0。
- 每次有效猜測都寫入 Google 試算表。
- 相同識別碼可讀取過去紀錄，並接續最近一局未完成的遊戲。
- 可查看舊局紀錄；除錯模式可查看該局答案。
- 不同識別碼的紀錄會分開顯示。

## 檔案
- `index.html`：前端網站。
- `Code.gs`：Google Apps Script 後端程式。
- `驗收紀錄.txt`：請依實際測試結果填寫。

## 設定 Google 雲端試算表與 GAS
1. 用 Google 帳號建立一份新的 Google 試算表，名稱可叫「猜數字遊戲版本三資料」。
2. 在試算表選「擴充功能」→「Apps Script」。
3. 將 Apps Script 編輯器原本的程式碼刪除，完整貼上 `Code.gs` 的內容，儲存。
4. 上方函式選單選 `setup`，按「執行」。第一次會要求授權，依畫面完成授權。
5. 回到試算表，確認出現 `Games` 和 `Guesses` 兩個工作表。
6. Apps Script 右上角選「部署」→「新增部署作業」。
7. 類型選「網頁應用程式」。
8. 「執行身分」選「我」；「誰可以存取」依課程要求選「任何人」（若學校帳號政策不允許，請依老師指示處理）。
9. 按部署，複製網址。網址通常以 `/exec` 結尾。
10. 打開 `index.html`，找到 `const API_URL = "請貼上你的_GAS_WEB_APP_EXEC_URL";`，把引號內文字換成剛複製的 `/exec` 網址，儲存。

## 上傳 GitHub Pages
1. 建立新的 Repository，例如 `guess-number-v3`。
2. 把修改好網址的 `index.html` 上傳到 Repository 最外層。
3. `Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)` → `Save`。
4. 等待 GitHub Pages 網站部署完成，再開啟網站測試。
5. `Code.gs` 不要放在公開網站也可以；建議保存在自己的作業資料夾中，作為 GAS 後端原始碼。

## 重要提醒
- 識別碼不是安全登入。任何知道別人識別碼的人，都可能讀取或更改該識別碼的遊戲資料；不要使用密碼、學號、電話或其他敏感資料。
- 此範例用 JSONP 讓 GitHub Pages 與 GAS 溝通，請勿把 API_URL 留在預設文字。
- 如果修改 GAS 後端程式碼，通常要到「部署」→「管理部署作業」→編輯，建立新版本並更新部署。
- 此版本需要你自己的 Google 試算表與 GAS 部署；我無法代替你登入 Google 或替你完成授權／部署。
